# Let's_Play_Maths
This is a simple fun numbers/maths game where a user can come to play different maths games and it's always better to play with numbers.
## About Let's_Play_Maths
On the home page the user will have 4 options of game to play with, USer will have a Home page (U will like it), a counter, Random number generator which has two games a dice game (Dice animation on clicking roll) and random numbers generator which will generate three random numbers (Dice animation on clicking roll), Number guessing game which is composed of 4 difficulty levels and finally a Temperature conversion program. Each one will have it's own page. I have made it using html, css and javascript.

# Getting Started and installation
## Dependencies
There are not much prerequisites, you just need to have a device it can be a windows laptop or pc system mac or even phone and internet connection to access the website and start playing 
## Installation
NO need of installation, People can access the website using the website link which is provided here too
It's a vercel Deployed Website it can can be opened on any OS be it andriod, windows or macOS
